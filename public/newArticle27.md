# はじめに

PHP2shellに関するニュースやメンテナンスのお知らせを見て、気になったことがありました。

こうしたニュースやお知らせは、エンジニアだけでなく、非エンジニアも目にします。

しかし、「PHP」や「脆弱性」といった専門用語を使っても、非エンジニアには何が起きているのか、なぜメンテナンスが必要になったのかが分からないのではないかと思いました。

また、理由が分からないことで、不安に思う人もいるのではないかと考えました。

自分としては、ニュースやメンテナンスのお知らせは、非エンジニアにも分かる言葉で書くべきだと思っています。

そこで今回は、PHP2shellによってメンテナンスが必要になった理由を、非エンジニアにも分かるように伝える方法を考えてみます。

# PHP2shellとは？

IPA（情報処理推進機構）は、PHP2shellについて以下のように説明しています。

> The PHP Groupが提供するPHPについて、メモリ不足(OOM)のエラー処理に起因する脆弱性（CVE-2026-109618）とリクエスト処理に関連する脆弱性（CVE-2026-109619）が報告されています。
> これらの脆弱性を悪用された場合、遠隔の第三者によって、任意のコード実行が実行される可能性があります。
>
> これらの脆弱性の組み合わせは「PHP2shell」と呼ばれています。

[^1]

また、IPAはThe PHP Groupによるセキュリティリリースの公開前にも、以下の注意喚起を行っていました。

> The PHP Groupが提供するPHPについて、2026年10月21日 23:00（日本時間）に、2つの脆弱性に対するセキュリティリリースを公開する予定であることが発表されています。
>
> - Upcoming Critical PHP Security Release
>
> また、脆弱性の詳細が公開された場合や、実際に悪用が確認された場合には、公開予定日時を前倒しする可能性があるとのことです。
>
> 本情報の発信時点では、セキュリティリリースは公開されておらず、これらの脆弱性の影響を受ける詳細なバージョン情報や、修正バージョン情報なども確認できていません。
>
> PHPを利用しているウェブサイトの運営者や、PHPを利用したウェブアプリケーションの開発者の皆様は、今後The PHP Groupが公開する情報を注視し、公開後、速やかにセキュリティリリースを適用するなどの対応ができるよう、事前準備をお願いします。可能な範囲で、開発・運用しているプログラムのうち、PHPを利用しているものを棚卸ししてください。

[^2]

このように、IPAの注意喚起は、主にシステムの開発者や管理者に対して対策を促すものなので、専門用語を使った説明でも問題ないと思います。

一方で、メンテナンスのお知らせは、開発者以外の利用者も目にします。

では、実際のメンテナンスのお知らせでは、どのように説明されていたのでしょうか。

# メンテナンスのお知らせ

PHP2shellの問題を受けて、複数のサービスでメンテナンスが実施されました。

今回は、その中からウマ娘 プリティーダービーと日向坂46の公式サイトの2つのお知らせを取り上げます。

まずは、ウマ娘 プリティーダービーのお知らせです。

> 「The PHP Group」から、本ゲームのサーバーで使用しているPHPに関する脆弱性が発見されたとの発表が行われました。
>
> 本脆弱性への対策として、システムの安全性を確保するため、下記の時間にメンテナンスを実施いたします。
>
> なお、現時点で、本脆弱性を悪用した被害や、ユーザーの皆さまのデータの流出は確認されておりません。

[^3]

続いて、日向坂46の公式サイトのお知らせです。

> このたび、サーバーで使用しているプログラミング言語「PHP」に関する脆弱性が発見されたとの発表を受け、セキュリティ強化及びシステム安全性を確保する緊急メンテナンスを実施いたします。
>
> 下記時間よりサイトへのアクセスができなくなります。
>
> お客様にはご不便、ご迷惑をお掛けいたしますが、何卒ご理解とご協力のほどよろしくお願い申し上げます。

[^4]

どちらのお知らせにも、「PHP」や「脆弱性」といった専門用語が使われています。

# 専門用語の深掘り

先ほど紹介したメンテナンスのお知らせには、「PHP」「The PHP Group」「脆弱性」といった専門用語が登場しました。

非エンジニアにも分かる文章に書き換えるために、まずはそれぞれの意味を調べてみます。

## PHPとは？

PHPの公式ドキュメントでは、PHPについて以下のように説明されています。

> PHP (PHP: Hypertext Preprocessor を再帰的に略したものです) は、広く使われているオープンソースの汎用スクリプト言語です。 PHP は、特に Web 開発に適しており、HTML に埋め込むことができます。

> PHP がクライアントサイド JavaScript のようなものと異なっている点は、 コードがサーバーで実行され、その結果がクライアントに送信されるということです。 クライアントは、スクリプトを実行した結果を受け取りますが、 その出力を作成したコードがどんなものなのかを知ることはできません。 全てのHTMLファイルをPHPで処理するようにWebサーバー を設定することさえ可能で、この場合、ユーザーはPHPが動いていることすら 知ることができません。

また、PHPでできることについても、以下のように説明されています。

> あらゆることができます。PHPでは主にサーバーサイドでの活用に焦点が 当てられているため、フォームからデータを取得したり、動的にページ の内容を生成したり、クッキーを送信・受信するといった他のCGI プログラムに出来ることは全て行うことが出来ます。しかし、これが 全てではありません。

[^5]

## The PHP Groupとは？

The PHP Groupについては、以下のような説明がありました。

> php.netを管理し、PHPの著作権を保有するグループ。The PHP FoundationやThe PHP Leagueは別の組織。

[^6]

また、php.netについては、以下のように記載されています。

> PHPの公式サイト。The PHP Groupが管理している。

[^7]

Wikipediaの説明からは、The PHP GroupはPHPをコミュニティベースで開発しているグループだと読み取れます。

> PHP（ピー・エイチ・ピー）は、 "The PHP Group" によってコミュニティベースで開発されているオープンソースの汎用プログラミング言語およびその公式の処理系であり、特にサーバーサイドで動的なウェブページを作成するための機能を多く備えていることを特徴とする。

[^8]

## 脆弱性とは？

![脆弱性.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/2284906/82a53e70-9b5c-4ceb-8cca-5b918aa8a305.png)

IPAが公開している「情報セキュリティ10大脅威 2025」の資料では、脆弱性について以下のように説明されています。

> ある製品やサービスに含まれる、セキュリティ上の弱点のことを指します。

[^9]

ここまで調べた内容をもとに、次は実際のメンテナンスのお知らせを自分なりに書き換えてみます。

# 自分ならどうするか？

ここまで調べた専門用語の意味を踏まえて、ウマ娘 プリティーダービーと日向坂46のメンテナンスのお知らせを、非エンジニアにも分かる文章に書き換えてみます。

## ウマ娘 プリティーダービー

まずは、元のお知らせを確認します。

> 「The PHP Group」から、本ゲームのサーバーで使用しているPHPに関する脆弱性が発見されたとの発表が行われました。
>
> 本脆弱性への対策として、システムの安全性を確保するため、下記の時間にメンテナンスを実施いたします。
>
> なお、現時点で、本脆弱性を悪用した被害や、ユーザーの皆さまのデータの流出は確認されておりません。

[^3]

専門用語を別の言葉に置き換えてみました。

本ゲームのサーバーで使用している処理を行うものにセキュリティ上の弱点が発見されたとの発表が開発元から行われました。

本セキュリティ上の弱点への対策として、システムの安全性を確保するため、下記の時間にメンテナンスを実施いたします。

なお、現時点で、本セキュリティ上の弱点を悪用した被害や、ユーザーの皆様のデータの流出は確認されておりません。

## 日向坂46の公式サイト

続いて、日向坂46の公式サイトのお知らせです。

> このたび、サーバーで使用しているプログラミング言語「PHP」に関する脆弱性が発見されたとの発表を受け、セキュリティ強化及びシステム安全性を確保する緊急メンテナンスを実施いたします。
>
> 下記時間よりサイトへのアクセスができなくなります。
>
> お客様にはご不便、ご迷惑をお掛けいたしますが、何卒ご理解とご協力のほどよろしくお願い申し上げます。

[^4]

こちらも専門用語を別の言葉に置き換えてみました。

このたび、サーバーで使用している処理を実行するためのものに関するセキュリティ上の弱点が発見されたとの発表を受け、セキュリティ強化及びシステム安全性を確保する緊急メンテナンスを実施いたします。

下記時間よりサイトへのアクセスができなくなります。

お客様にはご不便、ご迷惑をおかけいたしますが、何卒ご理解ご協力のほどよろしくお願い申し上げます。

# ファインマンテクニックを使ってみる

まずは、自分で専門用語を別の言葉に置き換えてみました。

次に、非エンジニアにも分かりやすく説明する方法として、ファインマンテクニックに着目しました。

今回は、生成AIのChatGPTに「ファインマンテクニック」という言葉を使って、メンテナンスのお知らせを書き換えてもらいました。

以前参加したイベントで、t_wadaさんがファインマンテクニックに触れられていました。

## ファインマンテクニックとは？

リチャード・P・ファインマンさんがファインマンテクニックに関わる以下の投稿をされていました。

> If you want to master something, teach it.

日本語訳([DeepL](https://www.deepl.com/ja/translator)を使用)：

> 何かをマスターしたいなら、それを教えてみることだ。

[^11]

分かりやすく説明してもらうために、ChatGPTへのプロンプトでも「ファインマンテクニック」という言葉を使ってみました。

# まとめ

サーバー上で実行され、処理を行うものに、セキュリティ上の弱点が見つかり、安全性を確保するために、メンテナンスを行った旨が伝われば良いと考えます。

また、「PHP」や「脆弱性」といった専門用語を使用する場合でも、分かりやすい説明を中心にして、専門用語自体は括弧内に補足として記載するべきだと考えます。

### 思ったこと
